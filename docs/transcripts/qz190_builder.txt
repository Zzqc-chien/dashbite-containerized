## Things that differ from the plan, or that I didn't do

1. **Smoke test Step 7b: the restart is not about 10 s.** Once the FIFO is removed, `docker compose restart preprocess` takes about 1 s. SIGTERM interrupts the blocked `open()`, Python retries it, and the retry fails because the path is gone. The worker then exits with a `FileNotFoundError` traceback, which is harmless. No command needs to change, so I left `plan.md` untouched. Only the comment "takes ~10 s" is inaccurate.
2. **`make stop` kills itself on Linux, and this is not new.** Its `pkill -f "python -m pipeline.…"` line matches the shell that is running it, so `make stop`, and therefore `make run`, exits with "Terminated". The baseline Makefile does the same on Linux (I checked). It's outside the plan's scope, so I didn't fix it. On macOS it may behave differently, but I couldn't check that here. I tested the host workflow with `make -o stop run` instead.
3. **Log noise I didn't touch:** preprocess prints a pandas `UserWarning` for each corrupted batch, which makes `make docker-logs` noisy. This comes from the pipeline logic, which the plan says not to change.
